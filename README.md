# ✨ Aura — Personal Profile Website

Aura is a simple, responsive personal profile website built using HTML, CSS, and JavaScript. It allows users to enter their personal information through a registration form and view their details on a separate profile page.

## 🌸 Features

- **User Registration:** Collects name, gender, mobile number, email address, city, state, and country.
- **Form Validation:** Checks required fields, email format, and 10-digit mobile numbers.
- **Profile Display:** Displays submitted information on a separate page.
- **Edit Profile:** Allows users to return to the form and update their details.
- **Local Storage:** Saves profile information in the browser.
- **Responsive Design:** Lavender-and-white theme with a clean, modern interface.
- **Clear Profile:** Allows users to remove their saved profile.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser Local Storage

## 🚀 How to Run

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open `index.html` using the Live Server extension, or open it directly in a browser.
4. Fill in the registration form and click **Create My Profile**.
5. View your information on the profile page.
6. Use **Edit Details** to update your information.

## 💾 Data Storage

Aura uses the browser's `localStorage` to save profile information. Data remains available in the same browser until it is cleared or removed.

This project does not use a backend or database. Registrations are stored separately in each visitor's browser and are not shared between users or devices.
